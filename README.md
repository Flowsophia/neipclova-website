# Neipclova — Complete English Website

This package contains the current static website, including Home, About, Technology, Applications, Gallery, Contact, all 01–07 sector pages and their assets.

## Upload
1. Extract the ZIP locally.
2. Upload the extracted files and folders to the repository root, keeping index.html at the root. Do not upload only the ZIP.
3. Preserve every asset folder and relative path.
4. In GitHub Pages settings, publish the main branch root (/), or use your existing deployment workflow.
5. Check navigation, images, gallery enlargement and mail links after publication.

The site requires no build step. Serve through HTTP/HTTPS; gallery-data.json is fetched by the Gallery page and may not load when opening files directly with file://.

Contact forms prepare mailto drafts; visitors send the email in their mail application. This package does not include an automatic email delivery server.

No domain activation is performed by extracting or uploading this package. Configure neipclova.com separately if required. No CNAME file is included because domain ownership and DNS settings were not verified.

The latest Home uses a single continuous original background. Includes Water Technology and Water Applications updates. Older update ZIPs are excluded to avoid duplicate versions.

Machinery and architectural concept images are illustrative. Ceramic originals and material samples retain their existing source files.
